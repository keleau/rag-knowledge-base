## 结论与边界

- Agent 的主要收益来自检索失败后的工具降级（读取文档分块）和无依据拒答；在 demo 模式下，回答由抽取式规则生成，词项覆盖率并不代表大模型的真实回答质量。
- 单次 RAG 只执行一次向量检索，没有证据门槛；遇到知识库没有的信息时，仍可能把不相关片段拼成回答，因此无答案拒答率明显低于 Agent。
- 本评测固定使用规则规划，结果可复现、零 API 成本；它验证的是编排、降级、引用校验与拒答逻辑，而不是 DeepSeek 的生成质量。
- demo 流式输出包含 10ms/片的人为节流，延迟主要反映交互节奏，不作为性能基准。
- 若接入真实模型，应另行记录 token 成本、规划耗时与工具调用准确率，再与单次 RAG 对比。
