# 知问 RAG 知识库问答系统 · 技术说明

## 系统定位

知问是一个面向个人与小团队的本地知识库问答系统。用户上传 TXT、Markdown、Word 或 PDF 文档后，系统会在本地完成文本解析、重叠分块与 TF-IDF 向量化；提问时先检索最相关的文档片段，再把片段与问题一起交给 DeepSeek 生成回答，并通过 SSE 将回答逐字推送到前端。

## 技术栈

- 后端：Python 3.11+、FastAPI、Uvicorn、httpx。
- 前端：Vue 3、TypeScript、Vite、marked、DOMPurify。
- 检索：jieba 中文分词、scikit-learn TfidfVectorizer、余弦相似度。
- 大模型：DeepSeek OpenAI 兼容接口，支持流式输出；未配置 API Key 时自动进入本地演示模式。
- 存储：JSON 文件，包含会话、消息、文档元数据与分块；上传的原始文件保存在 data/uploads。

## RAG 处理流程

1. 文档解析：按扩展名读取文本，Word 提取段落与表格，PDF 逐页提取。
2. 重叠分块：默认每块 500 字，相邻块重叠 80 字，避免上下文在边界处断裂。
3. 向量化：使用 jieba 分词后构建 TF-IDF 矩阵，文档更新时自动重建索引。
4. 相似度检索：将用户问题向量化，用余弦相似度排序，默认取前 4 个分块。
5. 提示词组装：把分块编号、来源文件名和正文放进系统提示词，要求模型标注引用。
6. 流式回答：后端解析 DeepSeek 的 SSE 数据，向前端转发 sources、delta、done 事件。
7. 引用留存：回答与来源分块一起写入会话，前端可以展开查看原文并跳转到文档分块。

## API 设计

- GET /api/health：返回模型、切片参数与知识库统计。
- GET/POST /api/conversations：会话列表与新建会话。
- GET/PATCH/DELETE /api/conversations/{id}：会话详情、重命名与删除。
- POST /api/conversations/{id}/messages/stream：流式提问，返回 SSE。
- GET/POST /api/documents：文档列表与上传。
- GET/DELETE /api/documents/{id}：文档详情与删除。
- GET /api/documents/{id}/download：下载原始文件。
- MCP 工具：search_knowledge、list_documents、get_document_chunks。

## 局限与演进方向

当前检索使用 TF-IDF，属于词面匹配，优点是零额外模型成本、可解释、启动快；缺点是难以理解同义改写与跨语言语义。生产环境可以把向量化替换为 bge-m3、text-embedding-3-small 等 embedding 模型，并使用 FAISS、Milvus 或 pgvector 存储向量；同时可以引入重排序模型、混合检索与多轮查询改写。

当前存储使用单进程 JSON 文件，适合个人使用与课程项目。多用户部署应迁移到 PostgreSQL，并为上传、解析、向量化引入任务队列。MCP 服务当前以 stdio 方式运行，便于在本地接入 Claude、Qoder 等支持 MCP 的客户端。
